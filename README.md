# Portofolio — Muhammad Rayhan Adriansyah

Situs portofolio statis (HTML, CSS, JavaScript murni, tanpa build) bertema lembar peta topografi.

## Isi
- **Hero** — peta kontur yang digambar procedural, pin kota-kota di Indonesia, dan pembacaan koordinat yang mengikuti kursor. Klik peta untuk menandai titik.
- **Tentang** — profil singkat.
- **Proyek GeoMap Kantor Pos Indonesia** — termasuk demo interaktif: cari kantor pos (nama, kota, kecamatan, kode pos), ketuk peta untuk menandai posisi lalu kantor pos terdekat otomatis dipilih, detail lokasi, dan tautan rute Google Maps. Data demo adalah contoh ilustratif.
- **Keahlian** dan **Kontak**.

## Yang perlu disesuaikan
Di bagian atas `script.js`:
- `CONTACTS` — ganti email, GitHub, LinkedIn dengan yang asli.
- `OFFICES` — data contoh kantor pos untuk demo.

Di `index.html` bagian Proyek: **Status** dan daftar **Teknologi** (sesuaikan dengan yang benar-benar dipakai).

## Menjalankan
Buka `index.html` langsung di browser, atau deploy ke GitHub Pages: *Settings → Pages → Deploy from branch → main / root*.
